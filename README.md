# Plásmalo — Ecommerce headless

Tienda online de ropa y merchandising personalizado (DTF, bordado) para empresas y eventos.

**Stack**: Next.js (App Router) + TypeScript + Tailwind CSS v4 + Shopify Storefront API (headless).

## Desarrollo

```bash
npm install
npm run dev        # servidor de desarrollo en http://localhost:3000
npm run check      # lint + typecheck + build
```

> Requiere Node.js >= 24 (ver `.nvmrc`).
